# 📦 Inventory & Sales Management System

A full-stack web-based Inventory and Sales Management System built using Flask and MySQL.  
It helps manage products, track stock, record sales/purchases, and generate real-time analytics.

---

## 🚀 Features

- Product management (Add, Update, Delete, View)
- Stock tracking system
- Low stock and out-of-stock alerts
- Sales and purchase transaction system
- Real-time dashboard analytics
- Monthly sales graph visualization
- Profit and profit margin calculation
- Inventory value and revenue tracking
- PDF report generation for products and transactions
- Category-wise analytics

---

## 🛠️ Tech Stack

- Backend: Flask (Python)
- Database: MySQL
- Frontend: HTML, CSS
- Charts: Chart.js
- PDF Generation: ReportLab

---

## ⚙️ How to Run

- Clone the repository
- Install dependencies using `pip install -r requirements.txt`
- Configure MySQL database in `db.py`
- Run the application using:
  - python app.py
- Open browser and go to:
  - http://127.0.0.1:5000/
